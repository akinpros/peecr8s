Fight Odds Scraper

An hourly pipeline that scrapes live fight odds, uses AI to parse the raw HTML into clean structured data, and upserts fighter records into a Supabase database for downstream use.

Client
Sports data project
Timeline

My Role
Pipeline & data modeling

The Challenge

Fight odds live on the web as messy HTML that changes constantly. Reading it manually - or with brittle scrapers that break on every layout tweak - was never going to be reliable.

The client needed a resilient pipeline that fetched odds on a schedule, turned the raw page into clean structured data, and kept a tidy database always up to date.

How It Works

  • Fetch: Every hour, Make.com makes an HTTP request to the odds source.
  • Parse to text: A text parser strips the HTML down to readable content.
  • AI extraction: OpenAI turns that messy text into clean, structured JSON.
  • Look up: Supabase is searched to see if each fighter record already exists.
  • Upsert: An if/else step updates existing fighters or creates new records - no duplicates.
